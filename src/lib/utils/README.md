# Carpeta: utils

Esta carpeta contiene funciones de ayuda genéricas y puras (sin estado) que pueden ser utilizadas en cualquier parte de la aplicación.

Ejemplos:
- `formatDate.ts` (Funciones para formatear fechas)
- `validations.ts` (Lógica de validación de campos)
- `constants.ts` (Variables constantes como URLs de la API o códigos de error)
