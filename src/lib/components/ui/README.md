# Carpeta: components/ui

Esta carpeta está destinada a contener componentes visuales reutilizables "tontos" o de presentación general.
Estos componentes no deben contener lógica de negocio ni llamadas a la API. Solo reciben propiedades (`props`) y emiten eventos.

Ejemplos:
- `Button.svelte`
- `Input.svelte`
- `Modal.svelte`
- `Card.svelte`
